## Selected work and labs

### AWS PrestaShop deployment
Deployed PrestaShop using an Ubuntu EC2 web/application server and a separate Amazon RDS MySQL database. Configured security-group-restricted EC2-to-RDS connectivity, Apache/PHP, SSH access, and database permissions. During installation, diagnosed an out-of-memory failure that caused Apache workers to be killed and resolved it with persistent swap before verifying the deployment.

### Virtualized Windows & Linux infrastructure lab
Built a multi-node lab with KVM/QEMU and libvirt using Windows Server, Windows 11, and Linux guests. Practised Active Directory, users/groups, Group Policy, virtual networking, service troubleshooting, and permissions.

### [Internal Network Discovery with Nmap](https://github.com/BenjaminChukwu05/Network_Discovery_Using_Nmap)
Used a bridged Kali Linux VM to discover hosts on a home network, troubleshoot subnet and reachability issues, enumerate services, and document the reasoning behind each step.

### [Study Engine Anki Toolkit](https://github.com/BenjaminChukwu05/study_engine_anki_toolkit)
Built a validation-first toolkit for maintaining structured Anki study material, including Python validators, synthetic fixtures, tests, and migration documentation. The project reflects the same approach I try to use in systems work: audit first, preserve data, make controlled changes, and verify the outcome.
