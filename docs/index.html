rclone-personal

Personal Google Drive integration for a Fedora Linux workstation.

What it does

This is a private-use Google OAuth desktop client for rclone, an open-source file-management tool. It allows the owner to access and manage their own Google Drive files from a Linux workstation, including browsing, mounting, backing up, copying, moving and deleting files when explicitly configured or requested.

The OAuth client requests Google Drive permissions that can include full read and write access. Google grants access only after the account owner authorizes the client. The authorization can be revoked at any time in the Google Account security settings.

How it is hosted

This page is an informational website hosted on GitHub Pages. It is not an authentication gateway, does not host the rclone program, and does not receive Google Drive files or OAuth access tokens. Actual Drive operations are performed by rclone on the owner's own computer.

Privacy and data handling

See the Privacy Policy for how Google Drive data and authorization credentials are accessed, used and stored.

Use

This OAuth client is intended for the account owner's personal use, not as a public service. It is not affiliated with or endorsed by Google, GitHub or the rclone project.
